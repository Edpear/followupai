🚀 Simple Chat Demo

Add a powerful AI chatbot to any page with just 1 line of code!

Super Simple Usage

1 Install the package:
npm install followupai
2 Add to your React component:
import { QuickChat } from 'followupai'; function MyPage() { return ( <div> <h1>My Website</h1> <QuickChat apiKey="your-groq-api-key" /> </div> ); }
3 That's it! You now have a fully functional AI chatbot.

Different Usage Options

🔑 With API Key

<QuickChat apiKey="your-key" />

🌍 With Environment Variable

// Set GROQ_API_KEY in .env <QuickChat />

🎨 Customized

<SimpleChat placeholder="Ask me anything..." style={{ maxWidth: '500px' }} />

📚 Multiple Chats

<div style={{display: 'grid', gridTemplateColumns: '1fr 1fr'}}> <QuickChat /> <QuickChat /> </div>

Features

  • ✅ One-line setup - Just import and use
  • ✅ Auto-generated questions - Creates multiple choice questions from any topic
  • ✅ Beautiful UI - Modern chat interface with typing indicators
  • ✅ Responsive design - Works on all devices
  • ✅ Customizable - Change colors, size, placeholder text
  • ✅ Error handling - Graceful error messages
  • ✅ Environment support - Use .env files for API keys

What Users Can Do

Users can ask the chatbot to generate questions about any topic:

"Create a question about JavaScript" "Generate a math problem for 5th graders" "Make a science quiz about the solar system" "Ask me about machine learning concepts"
